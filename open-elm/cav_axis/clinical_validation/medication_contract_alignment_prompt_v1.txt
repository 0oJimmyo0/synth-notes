contract and generated note. Do not infer missing facts.

Contract fields have distinct meanings:
- active_discharge_obligations: active medication/discharge actions that must
  be checked against the note.
- historical_context_only: inpatient or historical treatment; it is supported
  only as historical context and is not an active discharge medication.
- unknown_components: information intentionally unavailable. Unknown is never
  missing and can never support an automatic rejection.

Allowed statuses:
- present_supported: the note accurately expresses the contract item in its
  intended state.
- missing: an explicit active-discharge obligation is absent from the note.
- unsupported: the note asserts an active medication/action contradicted by, or
  absent from, the explicit contract.
- uncertain: the note adds a component marked unknown, the evidence cannot
  resolve the claim, or the note is ambiguous.

Rules:
1. Do not label a historical inpatient medication missing from the discharge
   list.
2. A note component where the contract says "not specified" is uncertain, not
   missing or unsupported.
3. Return one alignment for every supplied contract ID and no other IDs.
4. Set requires_human_review=true if any alignment is missing, unsupported, or
   uncertain. Otherwise set it to false.
